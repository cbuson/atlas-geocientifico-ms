# PATCH 02 · bibliografia acadêmica

Este patch é cumulativo sobre a V35 e já preserva a correção em português do PATCH 01 nos arquivos que volta a substituir.

Copie todo o conteúdo do ZIP por cima da pasta local do repositório `atlas-geocientifico-ms`.

Mantenha a estrutura de pastas.

Depois abra o GitHub Desktop.

Mensagem recomendada de commit

`PATCH 02 · bibliografia acadêmica por camada e índice`

Faça `Commit to main` e depois `Push origin`.

A PWA recebeu um novo nome de cache. Depois do GitHub Pages publicar o commit, abra o Atlas online e recarregue a página uma vez.

A página pública da bibliografia ficará disponível em

`/referencias/index.html`

Cada cartão de camada também passa a oferecer um link direto para a bibliografia correspondente.
