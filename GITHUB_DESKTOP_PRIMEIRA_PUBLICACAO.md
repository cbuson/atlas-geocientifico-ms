# ITA ARANDU MS · primeira publicação com GitHub Desktop

## Preparar a pasta

1. Descompacte o pacote V33 Beta em uma pasta de trabalho.

2. Abra GitHub Desktop e entre na sua conta do GitHub.

3. Escolha `File` e depois `New repository`.

4. Use como nome recomendado `ita-arandu-ms`.

5. Escolha uma pasta local onde o GitHub Desktop criará o repositório.

6. Clique em `Create repository`.

7. Abra a pasta criada pelo GitHub Desktop.

8. Copie para dentro dela todo o conteúdo descompactado da V33 Beta. Copie os arquivos e pastas do pacote, não o arquivo ZIP.

## Primeiro commit

1. Volte ao GitHub Desktop.

2. Em `Changes` confirme que aparecem `docs`, `README.md`, `data`, os arquivos de auditoria e os demais arquivos do projeto.

3. Em `Summary` escreva `ITA ARANDU MS V33 Beta com PWA`.

4. Clique em `Commit to main`.

## Publicar no GitHub

1. Clique em `Publish repository`.

2. Confirme o nome `ita-arandu-ms`.

3. Para a beta pública deixe desmarcada a opção `Keep this code private`.

4. Publique na sua conta pessoal.

5. Clique em `Publish repository`.

## Ativar GitHub Pages

1. No GitHub abra o repositório.

2. Entre em `Settings`.

3. No menu lateral escolha `Pages`.

4. Em `Build and deployment` escolha `Deploy from a branch`.

5. Em `Branch` escolha `main`.

6. Em pasta escolha `/docs`.

7. Clique em `Save`.

8. Aguarde o GitHub informar que o site está publicado.

## Atualizações seguintes

1. Substitua ou edite os arquivos dentro da mesma pasta local do repositório.

2. GitHub Desktop mostrará as mudanças.

3. Escreva uma mensagem curta em `Summary`.

4. Clique em `Commit to main`.

5. Clique em `Push origin`.

GitHub Pages será atualizado a partir de `/docs`.
