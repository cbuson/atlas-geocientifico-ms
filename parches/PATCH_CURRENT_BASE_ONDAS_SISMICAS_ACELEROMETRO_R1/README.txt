Instalacao
1. Descompacte esta pasta dentro de atlas-geocientifico-ms\parches
2. Abra PowerShell nesta pasta
3. Execute
   Set-ExecutionPolicy -Scope Process Bypass
   .\APLICAR_ONDAS_SISMICAS.ps1

O instalador valida SHA256 da base antes de alterar qualquer arquivo, cria backup e copia bytes sem regravar HTML como texto.
