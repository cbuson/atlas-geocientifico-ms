Provedor
GoatCounter

Antes de instalar

1. Crie manualmente um site em GoatCounter.
2. Guarde apenas o código do site.
   Exemplo
   https://ita-arandu.goatcounter.com
   código = ita-arandu
3. Nas configurações do site GoatCounter ative
   Allow adding visitor counts on your website

Instalação

Set-ExecutionPolicy -Scope Process Bypass
.\APLICAR_V38_4_37A_CONTADOR_VISITAS.ps1

O instalador pergunta o código GoatCounter.

Segurança

Nenhum token de API é colocado em index.html, JavaScript ou GitHub.
A leitura usa o contador público JSON do GoatCounter.
Durante desenvolvimento local, o comportamento padrão do count.js não contabiliza localhost.

O contador público do provedor pode usar cache de até quatro horas.
