# PATCH 06 · identidade visual reforçada e reconhecimento institucional

Este patch é cumulativo sobre a V35 e preserva os PATCH 01, 02, 03, 04 e 05.

Ele reúne na prática a linha do PATCH 05 com um reforço adicional da identidade visual no cabeçalho do Atlas.

Copie o conteúdo do ZIP por cima da pasta local do repositório `atlas-geocientifico-ms`.

Mensagem recomendada no GitHub Desktop

`PATCH 06 · identidade visual reforçada e reconhecimento institucional`

Depois faça `Commit to main` e `Push origin`.

Observação importante

O contador real de visitas continua preparado, mas não pode ser ativado automaticamente sem o código público da conta de analytics. Quando esse código existir, basta editar `docs/analytics/config.js`.
