PIG · Prioridade de Investigação Geocientífica

Gate metodológico V38.4.20

Princípio
PIG ordena prioridades relativas de investigação. Não mede favorabilidade mineral, probabilidade de jazida, recurso, reserva ou valor econômico.

Dois objetivos independentes

VCG representa vazios do conhecimento documentado. C_geo representa complexidade litoestratigráfica cartográfica da geologia de base.

Complexidade geológica de base

D_raw = N_eff - 1, com N_eff = exp(H) para diversidade areal das unidades. T_raw é a fração de transições entre unidades em pares adjacentes de uma micromalha global fixa de 2,5 km. Ambos são normalizados por P95 dentro de cada escala.

C_geo = 100 × sqrt(D* × T*)

É uma medida de heterogeneidade litoestratigráfica cartografada a 1:1.000.000. Não é densidade de falhas nem complexidade estrutural total.

Dominância de Pareto

Maximizam-se VCG e C_geo simultaneamente. Uma célula domina outra somente se não for pior em nenhum dos dois objetivos e for melhor em pelo menos um. Não existe soma ponderada. Empates permanecem empates.

O número do front de Pareto é a saída científica primária. Um PIG de 0 a 100 será apenas transformação ordinal do front para visualização, sem interpretação de distância intervalar.

Sensibilidade obrigatória

Micromalha 1,25 km, 2,5 km e 5 km. Normalização P90, P95 e P99. A versão final deverá auditar correlação, mudanças de classe, número de fronts e tamanho do primeiro front.

Referências

REF-002, REF-004 e REF-082 para o mapa geológico estadual. REF-105 para sensibilidade. REF-115 para o protocolo multiescalar. REF-116 para ordenação por dominância de Pareto.
