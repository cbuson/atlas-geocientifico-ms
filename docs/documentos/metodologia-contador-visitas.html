Contador agregado de visitas

ITA ARANDU MS · versão 1.0 · 15 de agosto de 2026

Finalidade

Registrar tendências agregadas de uso público do Atlas sem introduzir publicidade nem um sistema de identificação individual dentro do código científico.

Provedor

GoatCounter. Projeto de código aberto e serviço de análise orientado à privacidade. O rastreamento é carregado apenas no sítio público. O comportamento padrão do script não contabiliza endereços locais usados durante desenvolvimento.

Indicadores públicos

Visitas acumuladas, visitas no dia corrente, últimos sete dias e mês corrente. Os quatro valores são obtidos do contador público TOTAL com filtros temporais.

Privacidade

O Atlas não armazena no repositório chave de API do provedor. A leitura dos quatro indicadores usa somente o endpoint público de contador. Nenhum token privado é enviado ao navegador.

Atualização

O provedor informa que as respostas do contador público podem permanecer em cache por até quatro horas. Por isso os valores não devem ser interpretados como telemetria instantânea.

Limitações

Bloqueadores de conteúdo podem impedir o envio de uma visita. Falha de rede ou indisponibilidade do provedor deixa os indicadores sem atualização e não gera números simulados.

Referências utilizadas

As referências completas permanecem centralizadas no registro mestre de Referências, em APA 7.
