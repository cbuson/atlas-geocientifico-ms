Interpolação gráfica · Isopiezas

Ferramenta educativa para compreender a passagem de observações pontuais a uma representação de carga hidráulica. Mantém separados o exercício de interpolação linear e uma pré-visualização computacional exploratória.

Interpolação linear

Entre dois pontos A e B, para um valor V compreendido entre VA e VB, a fração é f = (V − VA) / (VB − VA). A posição é P = PA + f × (PB − PA).

Carga hidráulica

Quando a entrada representa cota do ponto de referência e profundidade vertical até o nível d’água, a ferramenta calcula de forma simplificada a cota do nível d’água pela diferença entre ambos. Os dados devem compartilhar datum, unidade e referência vertical compatíveis.

Pré-visualização

A tela de isopiezas utiliza ponderação pelo inverso da distância, IDW, exclusivamente como comparação exploratória. A tela de fluxo representa o gradiente descendente dessa superfície interpolada.

Limitações

Distribuição espacial dos poços, simultaneidade das medições, heterogeneidade, anisotropia, bombeamento, limites e estrutura geológica condicionam a interpretação. Uma superfície interpolada não demonstra sozinha a geometria nem o comportamento real do aquífero.
