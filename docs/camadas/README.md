# Camadas locais da beta V35

Camadas GeoJSON válidas separadas

26

Snapshots herdados com falha de integridade preservados para auditoria

2

Cada camada válida tem seu próprio arquivo em `arquivos`.

`catalogo-local.json` registra a camada, a fonte declarada, a validação, o número de feições e o tamanho.

Os blobs com falha de integridade ficam em `pendentes` e não são ativados no Atlas até reconstrução verificável.
